how to play

    
You write a tiny program that must decode to the target string exactly.
       Shorter is better. Beat par if you can. Par is provably optimal, so beating it is impossible;
       matching it is a perfect round.

    

      
tokenmeaningexample

      
plain textprints itself (1 char each)abc → abc

      
N{...}repeat the block N times4{ab} → abababab

      
~D,L~copy L chars from D backabcd~4,2~ → abcdab

      
\xliteral x (for digits, { } ~ \)\7 → 7

    

    
Backrefs copy from the decoded output as it grows, so ab~2,4~ gives ababab.
       Inside a { } block, a backref can only see inside that block.
